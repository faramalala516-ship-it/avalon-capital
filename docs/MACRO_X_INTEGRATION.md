# Macro-X Integration

Macro-X is an independent agent. Core never embeds Macro-X business logic.

Contract: `agents/templates/macro-x-mock/avalon-agent.json` + PromptRegistry seed.

Capabilities intended: register, start, workspace, events, Excel tools, macro DBs via data service, network sync via broker, local LLM via gateway, typed Windows actions via PrivilegeBroker.
